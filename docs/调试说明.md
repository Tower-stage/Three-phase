# Binodal 调试说明

## 问题背景
原代码基于 Flory-Huggins 理论计算 PM6-L8-Bo-溶剂三元体系的 binodal 相图，但运行后相图形状异常（arm 不光滑、分布零散、无明显相分离区）。本次调试系统性地扫描了关键参数 `X13`（L8-Bo/PM6 相互作用参数），并优化了求解策略。

---

## 关键发现

### 1. X13 是决定性参数
通过批量扫描 `X13 ∈ [0.45, 0.65]`，发现：

| 体系 | 最佳 X13 | 成功率 | 相图特征 |
|------|---------|--------|----------|
| Tol  | **0.62** | ~83% | 两条 arm 清晰，临界点位于 x3≈0.22 |
| O-Xy | **0.65** | ~85% | 相分离区略窄，临界点位于 x3≈0.21 |

- X13 < 0.55：相分离区极窄，大量迭代失败
- X13 > 0.65：成功率继续上升，但 arm 顶部开始出现回折

### 2. 热启动导致解分支跳跃
对比实验（见 `smooth_compare_Tol.png`）证明：
- **使用热启动**（用上一点的解作为下一点的初值）：arm 在 x3≈0.05 处出现明显回折，曲线不光滑
- **关闭热启动**（每点都从默认初值 `[0.2, 0.5, 0.5]` 开始）：曲线显著光滑，形状更正常

原因：热启动使优化器跟踪到错误的局部极小值分支，导致组成突变。

## 运行方式

### MATLAB（推荐，用于生成 CSV 数据）
```matlab
cd src/binodal-PM6-L8Bo-Tol
main
cd ../binodal-PM6-L8Bo-OXy
main
```
运行后生成 `binodal_PM6_L8Bo_*.csv`，可直接导入 Origin 绘制三元相图。

### Python（仅用于调参与验证）
需 Python 3.11+ 及 numpy、scipy、matplotlib。若使用 Windows 嵌入式 Python，路径示例：
```bash
~/.local/python/python.exe src/debug-tools/final_plot.py
```

## 后续建议
1. 若老师反馈相分离区偏大，可在 **±0.03** 范围内微调 X13（Tol: 0.59–0.65, O-Xy: 0.62–0.68）
2. 临界点附近 tie line 变短是物理合理现象，无需强行闭合
3. 如需更光滑的曲线，可在 Origin 中对 CSV 数据做样条平滑
