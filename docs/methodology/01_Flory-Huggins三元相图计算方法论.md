# Flory-Huggins 三元相图计算方法论

## 适用场景

本方法论适用于有机光伏（OPV）活性层材料的 **给体/受体/溶剂** 三元体系液-液相分离（LLPS）相图计算。可推广至任意高分子-小分子-溶剂三元共混体系。

---

## 1. 理论基础

### 1.1 Flory-Huggins 三元混合自由能

三元体系的混合 Gibbs 自由能为：

$$\frac{\Delta G_{mix}}{RT} = \frac{\phi_1}{v_1}\ln\phi_1 + \frac{\phi_2}{v_2}\ln\phi_2 + \frac{\phi_3}{v_3}\ln\phi_3 + g_{12}\phi_1\phi_2 + \chi_{13}\phi_1\phi_3 + g_{23}\phi_2\phi_3$$

其中：
- $\phi_1$ = 受体（Acceptor, 如 L8-Bo）体积分数
- $\phi_2$ = 溶剂（Solvent）体积分数
- $\phi_3$ = 给体（Donor, 如 PM6/D18）体积分数
- $v_i$ = 组分 i 的摩尔体积（基于晶格模型，单位为晶格位点数）
- $\chi_{13}$ = 给体-受体相互作用参数（常数）
- $g_{23}$ = 溶剂-给体相互作用参数（常数）
- $g_{12}$ = 受体-溶剂相互作用参数（**浓度相关**，通常为多项式函数）

### 1.2 相互作用参数物理意义

| 参数 | 对应界面 | 物理含义 | 增大效应 |
|------|---------|---------|---------|
| $\chi_{13}$ | 给体/受体 | 给体-受体排斥力 | 增强相分离驱动力，扩大两相区 |
| $g_{23}$ | 溶剂/给体 | 溶剂对给体的"溶剂质量" | 增大=不良溶剂，补偿 v3 降低造成的相分离驱动力损失 |
| $g_{12}$ | 受体/溶剂 | 受体-溶剂相容性 | 决定受体在溶剂中的溶解度，通常以多项式 $g_{12}(u_2)$ 建模 |

### 1.3 g12 浓度依赖性

受体-溶剂相互作用通常不是常数，需要以溶剂在受体-溶剂二元对中的体积分数 $u_2 = \phi_2/(\phi_1+\phi_2)$ 为自变量建模：

$$g_{12}(u_2) = p_1 + p_2 u_2 + p_3 u_2^2 + p_4 u_2^3 + p_5 u_2^4$$

该多项式的系数可通过 UNIFAC 基团贡献法初步估算，或通过实验三元相图数据反推优化。

## 2. 计算流程

### 2.1 总体 Pipeline

```
参数设定(v1,v2,v3,χ13,g23,g12)
        │
        ▼
  ┌─ Spinodal 网格扫描 ──→  det(G'')=0 等高线
  │
  ├─ Critical Point ────→  三阶条件符号变化插值
  │
  └─ Binodal + Tie-Lines ──→  fsolve 化学势等式
        │
        ▼
  单调性过滤 + 绘图 + 导出
```

### 2.2 第一步：Spinodal 计算

**目标**：确定体系亚稳态极限（旋节线），为临界点和结线计算提供相分离区域边界。

**方法**：
1. 在 $\phi_1 \times \phi_3$ 空间创建 1200×1200 网格
2. 在每个网格点计算 Hessian 矩阵 $G''$ 的行列式
3. 使用 `contour()` 提取 $\det(G'') = 0$ 等高线

**Hessian 矩阵**（对于三元体系，独立变量为 $\phi_1, \phi_3$）：
$$G'' = \begin{bmatrix} \frac{\partial^2 \Delta G}{\partial \phi_1^2} & \frac{\partial^2 \Delta G}{\partial \phi_1 \partial \phi_3} \\ \frac{\partial^2 \Delta G}{\partial \phi_3 \partial \phi_1} & \frac{\partial^2 \Delta G}{\partial \phi_3^2} \end{bmatrix}$$

Spinodal 条件：$\det(G'') = 0$ 且 $G''_{11} > 0$

**注意事项**：
- 对于 $g_{12}(u_2)$ 浓度依赖体系，须在求导时正确计入 $\partial g_{12}/\partial \phi_2$ 链式法则项
- 网格分辨率建议 ≥ 800×800，确保等高线光滑

### 2.3 第二步：Critical Point 计算

**目标**：确定旋节线与结线的交点——临界点（CP），此处两相组成完全相同。

**方法**：
1. 在已提取的旋节线等高线上逐点计算三阶量
2. 通过符号变化插值确定临界点位置

**三阶条件**（简化形式）：
$$\left.\frac{\partial^3 \Delta G_{mix}}{\partial \phi_1^3}\right|_{G''_{11}=0} = 0$$

**实用数值方案**：
- 提取 $\det(G'')=0$ 等高线的 $(\phi_1, \phi_3)$ 坐标
- 计算每个点的三阶导数符号
- 找到符号变化的相邻点对，线性插值确定 CP 精确位置

### 2.4 第三步：Binodal + Tie-Line 计算

**目标**：计算共存相组成——浓相（给体富集）和稀相（受体富集），并用结线连接。

**方法**：固定稀相 $\phi_3^{dil}$ 值，求解化学势等式系统：

$$\mu_i^{conc}(\phi_1^{conc}, \phi_2^{conc}, \phi_3^{conc}) = \mu_i^{dil}(\phi_1^{dil}, \phi_2^{dil}, \phi_3^{dil}), \quad i=1,2,3$$

其中 $\phi_2 = 1 - \phi_1 - \phi_3$（物质守恒），所以实际未知数为 3 个：
- $\phi_1^{conc}$（浓相受体体积分数）
- $\phi_3^{conc}$（浓相给体体积分数）
- $\phi_1^{dil}$（稀相受体体积分数）

**化学势公式**（组分 1 为例）：
$$\frac{\mu_1}{RT} = \frac{1}{v_1}\ln\phi_1 + \left(\frac{1}{v_1}-\frac{1}{v_2}\right)\phi_2 + \left(\frac{1}{v_1}-\frac{1}{v_3}\right)\phi_3 + g_{12}\phi_2(1-\phi_1) - \chi_{13}\phi_1\phi_3 - g_{23}\phi_2\phi_3 + \frac{\partial g_{12}}{\partial \phi_1}\phi_1\phi_2$$

组件 2 和 3 的化学势通过循环置换角标获得。

**数值求解器**：使用 MATLAB `fsolve`（而非 `fmincon`）。

## 3. 关键算法决策与已知陷阱

### 3.1 为什么使用 fsolve 而非 fmincon

| 方法 | 适用场景 | 此问题中的问题 |
|------|---------|-------------|
| **fmincon** | 最小化残差平方和 | 会收敛到平凡解（两相组成完全相同，残差=0 但是无效的物理解） |
| **fsolve** | 直接求解等式系统 | 正确寻找化学势相等的非平凡解 | 

**结论**：必须使用 fsolve 直接求解化学势等式系统，不能将问题转化为平方和最小化。

### 3.2 多初始猜测策略（避免分支跳跃）

**问题**：如果使用单一起始猜测（或热启动——以上一点的解作为下一点的初始值），求解器容易"跳"到错误的解分支，导致结线不光滑。

**解决方案**：对每个 $\phi_3^{dil}$ 点，使用 **8 个独立初始猜测**：

```matlab
% 8 个覆盖参数空间不同区域的初始猜测
guesses = [
    [0.1, 0.8, 0.1];   % 浓相：低受体，高给体
    [0.2, 0.7, 0.1];
    [0.3, 0.6, 0.1];
    [0.4, 0.5, 0.1];
    [0.5, 0.4, 0.1];   % 稀相：高受体
    [0.6, 0.3, 0.1];
    [0.7, 0.2, 0.1];
    [0.8, 0.1, 0.1];
];
```

对每个猜测运行 fsolve，选择收敛且物理合理（$\phi_i \in [0,1]$）且残差最小的解。**不使用热启动**。

### 3.3 单调性约束

**物理要求**：
- 浓相 $\phi_3^{conc}$ 应随 $\phi_3^{dil}$ 增大而**单调递减**
- 稀相 $\phi_3^{dil}$ 自身为控制变量，应**单调递增**

**实施**：后处理步骤中检查单调性，移除非单调点。

### 3.4 迭代变量起点选择

稀相控制变量 $\phi_3^{dil}$ 的扫描范围应从刚超过临界点处开始。经验法则：
- 起始点：$\phi_3^{dil} \approx \phi_3^{CP} \times 0.1$
- 终止点：$\phi_3^{dil} \approx \phi_3^{CP}$（趋近临界点）
- 步数：建议 60-120 步

## 4. 参数估算方法

### 4.1 摩尔体积 vi

- **溶剂 v2**：通过分子量和密度计算（如 Toluene v2 ≈ 106.3, o-Xylene v2 ≈ 120.6）
- **受体 v1**：通过 UNIFAC 基团贡献法或分子体积估算（如 L8-Bo v1 ≈ 1132.1）
- **给体 v3**：高分子摩尔体积通常极大（如 PM6 直接估算值 v3 ≈ 1,743,900），但**需要大幅下调**（见 4.3）

### 4.2 g12 初始估算

使用 UNIFAC 基团贡献法或 HSP 差异估算：
$$\chi_{12} \approx \frac{v_{ref}}{RT}[4(\Delta\delta_d)^2 + (\Delta\delta_p)^2 + (\Delta\delta_h)^2] + 0.34$$

然后拟合为 $u_2$ 的多项式。

### 4.3 v3 下调（关键工程近似）

**问题**：给体（如 PM6）作为高分子，其摩尔体积高达 $10^6$ 量级。当 v3 极大时，给体混合熵近似为零，导致极微弱的焓排斥即可触发相分离，计算出的两相区过于狭窄，不符合实验。

**解决方案**：将 v3 作为**有效参数**大幅下调（通常下调 1-2 个数量级）：

| 体系 | 原始 v3 | 优化后 v3 | 下调倍数 |
|------|--------|-----------|---------|
| PM6-Tol | 1,743,900 | 100,000 | 17× |
| PM6-OXy | 1,743,900 | 120,000 | 15× |
| D18-Tol | ~1,000,000 | 60,000 | 17× |
| D18-OXy | ~1,000,000 | 100,000 | 10× |

**物理依据**：v3 下调反映高分子链的柔性降低（刚性共轭高分子链段独立运动单元远小于整链），以及聚集态下的有效链段体积。

## 5. 输出数据格式

### 5.1 Binodal CSV 结构

每两行代表一对共存相（1 条 Tie-line）：

| 行 | 含义 | 列结构 |
|----|------|--------|
| 奇数行 (1,3,5...) | 浓相（给体富集） | residual, phi1_L8Bo, phi2_Solvent, phi3_Donor |
| 偶数行 (2,4,6...) | 稀相（受体富集） | residual, phi1_L8Bo, phi2_Solvent, phi3_Donor |

### 5.2 质量检查标准

- 残差 < 10⁻⁶（理想情况下 < 10⁻¹⁰）
- 浓相 $\phi_3$ 单调递减
- 稀相 $\phi_3$ 单调递增
- 成功率达 80% 以上（即 120 个控制点中 ≥ 96 个收敛）
