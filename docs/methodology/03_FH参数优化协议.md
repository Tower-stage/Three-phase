# Flory-Huggins 三元相图参数优化协议

## 适用场景

当需要对新给体/受体/溶剂体系建立三元相图模型时，三大相互作用参数（χ13, g23, g12）和给体有效摩尔体积（v3）需要系统性地优化，以使计算相图与实验观测一致，且计算过程数值稳定。

---

## 1. 参数空间定义

### 1.1 待优化参数

| 参数 | 类型 | 自由度 | 物理含义 |
|------|------|--------|---------|
| v3 | 标量 | 1 | 给体有效摩尔体积 |
| χ13 | 标量（常数） | 1 | 给体-受体相互作用 |
| g23 | 标量（常数） | 1 | 溶剂-给体相互作用 |
| g12 多项式系数 p1-p5 | 标量×5 | 5 | 受体-溶剂浓度依赖性 |

**总搜索空间**：8 维（v3, χ13, g23, p1-p5）。实际优化中，p1-p5 通常由 UNIFAC 或 HSP 差异估算锁定，仅优化 v3 + χ13 + g23（3 维）。

### 1.2 参数边界

| 参数 | 下限 | 上限 | 依据 |
|------|------|------|------|
| v3 | 5,000 | 原值的 50% | 原值（~1.7×10⁶）严重高估；下限保证物理意义 |
| χ13 | 0.40 | 1.00 | χ13 < 0.4 相分离太弱；χ13 > 1.0 可能不物理 |
| g23 | 0.15 | 1.00 | g23 < 0.15 溶剂过于良溶剂；> 1.0 可能引发沉淀 |

---

## 2. 评分函数设计

### 2.1 核心评分公式

对每组参数 (v3, χ13, g23)，运行完整的 Spinodal → Critical Point → Binodal 计算，提取以下质量指标：

$$\text{Score} = w_1 \times \text{SuccessRate} + w_2 \times \text{RangeScore} + w_3 \times \text{BalanceScore} - w_4 \times \text{ResidualPenalty}$$

### 2.2 各分项定义

**SuccessRate**（成功率）：
$$\text{SuccessRate} = \frac{\text{成功收敛的 tie-line 数}}{\text{尝试的控制点数}}$$

目标 > 80%（即 120 个控制点中 ≥ 96 个成功）。

**RangeScore**（两相区范围得分）：
$$\text{RangeScore} = \min\left(1.0, \frac{\phi_3^{max} - \phi_3^{min}}{0.50}\right)$$

其中 $\phi_3^{max}$ 和 $\phi_3^{min}$ 取自浓相结线端点。分母 0.50 是合理的最大范围期望值。

**BalanceScore**（对称性得分）：
$$\text{BalanceScore} = 1.0 - \left|\frac{\phi_1^{dil}}{\phi_3^{conc}} - 1.0\right|$$

衡量稀相受体富集与浓相给体富集的对称性。目标值接近 1.0 表示相图大致对称。

**ResidualPenalty**（残差惩罚）：
$$\text{ResidualPenalty} = \log_{10}(1 + \text{mean\_residual})$$

当平均残差 > 10⁻³ 时开始显著扣分。

### 2.3 默认权重

| 权重 | 默认值 | 侧重场景 |
|------|--------|---------|
| w1（成功率） | 0.40 | 始终最重要——没有收敛就没有相图 |
| w2（范围） | 0.30 | 需要两相区有足够的实验可观测性 |
| w3（对称性） | 0.20 | 物理合理性 |
| w4（残差） | 0.10 | 数值质量 |

## 3. 网格扫描策略

### 3.1 三阶段扫描

```
阶段一：粗扫描（快速定位参数盆地）
├── v3:  对数间隔, 5-8 个采样点（如: 5000, 20000, 50000, 100000, 200000, 500000, 1000000）
├── χ13: 线性间隔, 8-12 个采样点（如: 0.50:0.05:1.00）
├── g23: 线性间隔, 4-6 个采样点（如: 0.20:0.10:0.60）
└── 总计: 5×10×5 = 250 组合 → 锁定 Top 10

阶段二：精细扫描（Top-10 邻域细化）
├── 以每个 Top 参数为中心 ± 30%
├── 每维 3-5 个细采样点
└── 总计: 10×(3×3×3) = 270 组合 → 锁定 Top 3

阶段三：验证与物理判断
├── 运行完整计算（120 tie-lines）
├── 检查 CP φ2 合理性
├── 检查两相区形状（不应有异常扭曲）
└── 对比实验 PCE 趋势
```

### 3.2 搜索空间实例

以下为 PM6/L8-Bo/o-Xylene 体系的实际扫描配置（192 组合）：

```matlab

            120000, 150000, 200000, 300000, 500000, 1743900];  % 13 steps
```

## 4. 参数调优规律

### 4.1 三大规律的物理机制

#### 规律一：v3 下降 → 相图向中心展宽

```
v3 极大（~10⁶）：给体混合熵 → 0 → 相分离只需极弱驱动力
                → 两相区狭窄地贴附在给体-受体轴上
v3 下调（~10⁴）：给体获得有限混合熵 → 需要更强的焓驱动力
                → 两相区向三元图中心扩展 → 可以观察到实验范围的相分离
```

**操作指南**：
- 先固定 χ13 和 g23 为中等值（如 0.70, 0.35）
- 从高到低调 v3，观察两相区何时扩展到目标范围
- 两相区中心应大致覆盖 φ2 = 0.4-0.8 范围

#### 规律二：χ13 ↑ → 两相区扩大

```
χ13 = 给体-受体排斥力
增大 χ13 → 更强的给体-受体相分离驱动力
        → Spinodal 区域扩大
        → Binodal 两相区扩大
        → CP φ2 升高（更早触发相分离）
```

**操作指南**：
- 找到能产生合理 CP φ2（目标范围）的最小 χ13
- χ13 过大会导致相分离过强，高估实际相分离程度
- 参考范围：0.45-0.95

#### 规律三：g23 ↑ → 补偿 v3 降低造成的相分离驱动力不足

```
g23 = 溶剂-给体排斥力（不良溶剂程度）
降低 v3 → 给体混合熵增加 → 相分离驱动力降低
提高 g23 → 溶剂-给体排斥增强 → 相分离驱动力恢复
→ 两者存在耦合互补关系
```

**操作指南**：
- v3 和 g23 必须联合优化
- v3 大幅下调 → g23 必须相应上调
- 但 g23 也不宜过高（物理上相当于极不良溶剂）

### 4.2 参数耦合关系矩阵

| 如果... | 则... |
|---------|-------|
| 两相区太窄 | ↑ χ13 或 ↑ g23 或 ↓ v3 |
| 两相区太宽 | ↓ χ13 或 ↓ g23 或 ↑ v3 |
| CP φ2 过高 | ↓ χ13 或 ↓ g23 |
| CP φ2 过低 | ↑ χ13 或 ↑ g23 |
| 收敛率低（< 70%） | ↓ χ13（过于陡峭的化学势梯度导致 fsolve 发散）|
| 结线异常弯曲 | 调 p4、p5（调整 g12 在高 u2 区的曲率） |

## 5. 收敛性优化技巧

### 5.1 提高 fsolve 收敛率

```matlab
options = optimoptions('fsolve', ...
    'Display', 'off', ...
    'Algorithm', 'trust-region-dogleg', ...  % 或 'levenberg-marquardt'
    'MaxIterations', 1000, ...
    'MaxFunctionEvaluations', 5000, ...
    'FunctionTolerance', 1e-12, ...
    'StepTolerance', 1e-12, ...
    'OptimalityTolerance', 1e-12);
```

### 5.2 初始猜测分布优化

8 个初始猜测应按以下方式分配，以确保覆盖两相共存区的不同角落：

```
猜测 1-3：偏向浓相、低受体（cover φ1=0.05-0.25, φ3=0.60-0.85）
猜测 4-6：偏向中间（φ1=0.20-0.50, φ3=0.20-0.50）
猜测 7-8：偏向稀相、高受体（φ1=0.60-0.85, φ3=0.05-0.15）
```

### 5.3 临界点附近处理

靠近临界点时，两相组成趋同，化学势梯度退化，fsolve 自然难以收敛。这是**物理现象而非数值问题**：
- 在 120 个控制点中，最后 5-10 个点（最靠近 CP）失败是正常的
- 如果 110+ 个点成功，已足够
- 不要试图通过调整参数迫使临界点附近收敛——这通常导致参数偏差

## 6. 实验结果验证协议

### 6.1 定性验证

- [ ] 相图两相区存在且形状合理（近似对称或略有偏斜）
- [ ] CP 在 Spinodal 和 Binodal 的交点处（不会偏离）
- [ ] Tie-line 从临界点向外逐渐增长
- [ ] 浓相和稀相组成随控制变量单调变化

### 6.2 半定量验证

- [ ] CP φ2 排序与实验 PCE 排序一致（CP φ2 越低 → PCE 越高）
- [ ] 同给体-不同溶剂体系的 CP φ2 趋势与器件性能趋势一致
- [ ] g23 排序与溶剂质量直觉一致（良溶剂 < 不良溶剂）

### 6.3 定量交叉验证

- [ ] 与独立测量的 χ 参数（如通过熔点降低法或反气相色谱）对比
- [ ] 与溶解/溶胀实验（原位椭偏）结果对比
- [ ] 预测的 PCE 增量与实际增量在 ±0.2% 绝对偏差内

## 7. 新体系参数化流程（从零开始）

```
1. 获取分子信息
   └── SMILES → UNIFAC 基团分解 → 初始 FH 参数估算

2. HSP 计算
   └── Hoftyzer-van Krevelen → δd, δp, δh → Ra 矩阵

3. 粗扫描（250-676 组合）
   └── 锁定参数盆地的 Top 10 候选

4. 细扫描（270 组合）
   └── 锁定 Top 3

5. 完整计算（120 tie-lines × 3 候选）
   └── 对比 CP φ2、两相区形状、残差分布

6. 最终选择
   └── 选取收敛率 > 85%、CP φ2 合理、两相区自然的参数组

7. 实验验证
   └── 器件制备 → PCE 测量 → 与 CP φ2 预测对比

预计时间：2-3 天（含计算 + 参数扫描），不含实验
```

## 9. 常见问题排查

| 症状 | 可能原因 | 解决方案 |
|------|---------|---------|
| 几乎所有参数组合都失败 | v3 太大或太小 | 先固定 χ13=0.70, g23=0.35，仅扫描 v3 找到可行区间 |
| 相图总是太窄 | v3 太大 | 继续下调 v3，或增大 χ13 |
| 相图总是太宽 | v3 太小 | 上调 v3，或减小 χ13 |
| CP 出现在边缘 | g23 偏高 | 降低 g23 |
| 结线在中间断裂 | 初始猜测不覆盖该区域 | 增加中间区域的猜测点 |
| 残差突然增大 | g12 多项式在边界处行为异常 | 检查 p4、p5 值 |
