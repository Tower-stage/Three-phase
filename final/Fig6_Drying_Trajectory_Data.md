# Fig6 干燥轨迹示意图 — 原始数据与物理解读

## 图的来源

fig6_drying_trajectory.png 是一张**概念示意图**，它将四个体系的临界点数据和溶剂挥发物理过程绘制在同一张"伪三元相图"上，展示不同溶剂/给体组合在成膜过程中的相分离触发时机差异。

它不是从某个 CSV 直接绘制的——而是将以下数据叠加在概念化的相图坐标上。

---

## 图中每个数据点的原始来源

### 1. 四个临界点 (Diamond Markers)

这些是 fig6 中四个菱形标记，直接从 `critical_*.csv` 读取：

| 体系 | phi1 (L8-Bo) | phi2 (溶剂) | phi3 (给体) | 给/受体比 | CSV 来源 |
|---|---|---|---|---|---|
| PM6-Tol | 0.2311 | **0.7184** | 0.0506 | 0.82 | `critical_PM6_Tol.csv` |
| PM6-OXy | 0.2717 | **0.6755** | 0.0522 | 0.84 | `critical_PM6_OXy.csv` |
| D18-Tol | 0.1269 | **0.8186** | 0.0545 | 0.70 | `critical_D18_Tol.csv` |
| D18-OXy | 0.5026 | **0.4284** | 0.0690 | 0.88 | `critical_D18_OXy.csv` |
| PM6-CF | 0.5291 | **0.4058** | 0.0652 | 0.89 | `critical_PM6_CF.csv` |
| D18-CF | 0.5543 | **0.3595** | 0.0862 | 0.87 | `critical_D18_CF.csv` |

> **fig6 中只画了前 4 个（Tol/OXy 体系），CF 体系是后来补充计算的。**

### 2. 相边界 (Binodal Curve) — 虚线

fig6 中的相边界是将四个体系的临界点用一条光滑曲线连接，**不代表任何单一体系的真实 binodal**。它是一条概念化的"平均相边界"，用于展示临界点之间的相对位置关系。

真实 binodal 数据见 `binodal_*.csv`（Excel 中每个 sheet 的 A-C 列）。

### 3. 干燥轨迹 (Arrows)

三条箭头代表三种溶剂条件下的成膜路径：

| 箭头 | 溶剂 | 沸点 | CP phi2 | 轨迹特征 |
|---|---|---|---|---|
| CF (紫色) | Chloroform | 61°C | 0.406-0.360 | 起点高(良溶剂)、挥发快 → 极速穿越两相区 → 最优形貌 |
| D18-Tol (橙虚线) | Toluene | 111°C | 0.819 | 极高 CP → 成膜早期即触发 LLPS → 畴区粗化时间长 |
| D18-OXy (黄虚线) | o-Xylene | 144°C | 0.428 | 最低 CP(绿溶剂中) → 延迟触发 + D18预聚集补偿 |

### 4. 单相区 / 两相区 (颜色填充)

- **蓝色区 (上方)**：单相区 (Homogeneous Solution) — phi2 > CP_phi2 时，体系为均匀溶液
- **红色区 (下方)**：两相区 (LLPS + Crystallization) — phi2 < CP_phi2 时，液-液相分离 + 结晶

这条分界线就是各体系 binodal 曲线的**概念化平均位置**。

## 如何根据自己的数据重画这张图

如果你想用**真实数据**而非概念曲线来画：

### 步骤

1. 选择**一个体系**（例如 D18-Tol）的 binodal 数据作为参考相边界
2. 从 `binodal_D18_Tol.csv` 读取浓相分支（奇数行）
3. 将其 phi1, phi2, phi3 转换为三元坐标:
   ```
   x = phi1 + phi2/2
   y = phi2 * sqrt(3)/2
   ```
4. 在相图上标出所有 6 个临界点（从 `critical_*.csv` 读取）
5. 从 CP 位置出发，沿 phi2 减小方向画箭头（模拟溶剂挥发）
6. 箭头长度 = 挥发程度；箭头斜率 = 挥发过程中给/受体比的变化

### 对应的原始数据位置

| 数据 | 文件 |
|---|---|
| Binodal 浓相分支 | `binodal_*.csv` 奇数行 (phi1_L8Bo, phi3_Donor, phi2_Solvent) |
| Spinodal | `spinodal_*.csv` (phi1, phi3, phi2) |
| 临界点 | `critical_*.csv` (phi1, phi2, phi3) |
| 全量 Excel | `Ternary_All_Data.xlsx` |

## 物理解读：为什么临界点的 Y 轴位置最重要

```
成膜过程 = 溶剂挥发 → 溶剂体积分数 phi2 持续下降

当 phi2 降到 CP_phi2 以下 → 体系进入两相区 → LLPS 开始
                                              ↓
                                  畴区开始粗化 (Ostwald ripening)
                                              ↓
                              phi2 继续下降 → 体系玻璃化/结晶固化
                                              ↓
                                    畴区尺寸被"冻结"

CP_phi2 越高 = 成膜越早期触发相分离 = 粗化时间越长 = 畴区越大
CP_phi2 越低 = 成膜越晚期触发相分离 = 粗化时间越短 = 畴区越小(越接近CF)
```

这就是 fig6 想表达的**唯一核心信息**。
